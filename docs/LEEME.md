# Carpeta docs: demo web

Ponga aquí su demo web **solo si su producto se ve en el navegador**. Debe haber un archivo `index.html` en esta carpeta.

- Por navegador, cada archivo puede pesar máximo 25 MB. Con GitHub Desktop, menos de 100 MB.
- Unity WebGL: en *Player Settings > Publishing Settings* use **Compression Format: Disabled** o active **Decompression Fallback**. GitHub Pages no sirve builds comprimidos sin esa opción.
- No borre el archivo `.nojekyll`.
